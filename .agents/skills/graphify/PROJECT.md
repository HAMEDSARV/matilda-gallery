# Graphify برای پروژه ماتیلدا

منبع: https://github.com/Graphify-Labs/graphify
کامیت آخر شاخه اصلی هنگام دریافت: 8e6a6d2129d4aeffc7a0e9ed79b153f7f057f42b
تاریخ: 2026-11-03

اسکیل رسمی Codex از graphify/skill-codex.md و تمام references همراه آن در همین پوشه نصب شده‌اند. مجوزهای بالادستی حفظ شده‌اند. اسکیل token-optimizer کنار این پوشه باقی مانده است.

CLI نسخهٔ 0.9.101 از همان کامیت بالا در محیط اختصاصی `.venv-graphify` با Python 3.12 نصب شده است. اجرای محلی: `.\.venv-graphify\Scripts\graphify.exe`؛ فعال‌سازی محیط یا نصب سراسری لازم نیست.

گراف گردش کار در `graphify-out/graph.json` و نمای تعاملی در `graphify-out/graph.html` قرار می‌گیرند. دامنه در `.graphifyignore` مشخص است: اسکریپت‌های پروژه، AGENTS.md، SKILL.md، README.md، CONTENT_RULES.txt و دو الحاقیهٔ نورپردازی و جلای فلز. تصاویر محصول، خروجی‌ها، فایل‌های DOCX پرامپت دسته‌ها، وابستگی‌ها و اسکیل‌های فروشنده عمداً تحلیل نمی‌شوند. گراف مسیر یافتن منبع است و جای خواندن کامل پرامپت دسته هنگام تولید تصویر را نمی‌گیرد.

برای جست‌وجوی کم‌حجم از `.\.venv-graphify\Scripts\graphify.exe query "موضوع" --budget 1500` استفاده کن. کل JSON یا HTML را وارد گفتگو نکن. نتیجه را با منبع واقعی تطبیق بده؛ اسناد ممکن است تصمیم‌های تاریخی یا محدودیت‌های حل‌نشده داشته باشند.

برای بازسازی، `.\.venv-graphify\Scripts\python.exe scripts/graphify-project.py prepare` کش AST و اسناد را بررسی می‌کند. فقط اسناد ناموجود در کشِ `graphify-out/.graphify_uncached.txt` باید مطابق extraction-spec و با پوشش کامل خوانده و در `.graphify_chunk_01.json` استخراج شوند. سپس همین اسکریپت را با آرگومان `build` اجرا کن و `graphify export html` بگیر. بازسازی خودکار در هر گفتگو انجام نشود. هزینهٔ واقعی مدل در این پلتفرم قابل اندازه‌گیری نبوده و در cost.json نامعلوم ثبت می‌شود؛ صرفه‌جویی اندازه‌گیری‌شده‌ای ادعا نشده است.

برای کار معمول، جست‌وجوی هدفمند ارجح است. ساخت گراف معنایی از تمام تصاویر و اسناد می‌تواند مصرف مدل را افزایش دهد؛ آن را خودکار هنگام بازکردن پروژه اجرا نکن. اگر گراف موجود است، query را با بودجه محدود استفاده کن و برای تغییرات فقط update انجام بده.
