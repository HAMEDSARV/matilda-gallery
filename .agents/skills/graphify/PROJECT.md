اسکیل رسمی Codex از graphify/skill-codex.md و تمام references همراه آن در همین پوشه نصب شده‌اند. مجوزهای بالادستی حفظ شده‌اند. اسکیل token-optimizer کنار این پوشه باقی مانده است.

این نصب فقط اسکیل پروژه‌ای است. CLI و وابستگی‌های تحلیل Graphify با این عملیات نصب نشده‌اند و گرافی ساخته نشده است. اجرای فرمان‌های graphify نیازمند نصب CLI است؛ در نبود آن، محدودیت را اعلام کن و خروجی گراف ساختگی نساز.

برای کار معمول، جست‌وجوی هدفمند ارجح است. ساخت گراف معنایی از تمام تصاویر و اسناد می‌تواند مصرف مدل را افزایش دهد؛ آن را خودکار هنگام بازکردن پروژه اجرا نکن. اگر گراف موجود است، query را با بودجه محدود استفاده کن و برای تغییرات فقط update انجام بده.
